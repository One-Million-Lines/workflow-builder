# Contributing

Thanks for your interest in contributing.

## Local setup

```bash
npm install
npm run dev
```

## Making changes

- Keep new step types and schemas in `definitions/`
- Update the example in `examples/vanilla/` when you add or change public behavior
- Run `npm run build` before opening a pull request

## Pull requests

1. Fork the repository
2. Create a branch for your change
3. Make your changes
4. Open a pull request with context and sample workflows when relevant

## Reporting issues

Open a GitHub issue with reproduction steps, browser details, and the workflow JSON that triggered the problem.
